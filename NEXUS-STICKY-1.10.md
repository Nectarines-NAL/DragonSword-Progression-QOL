# PROGRESSION QOL 0.9.4 RC1 — DRAGONSWORD 1.0.10

Progression QOL has been revalidated for DragonSword: Awakening 1.0.10, Steam build 24831799.

What changed:

- Added a separate Currency EXP Items multiplier for Character, Equipment, and Karma EXP items from the three repeatable Currency Dungeons.
- Added Sunken Ruins and Ruins Beneath the Waves to the existing Activity Gold and Crafting Materials controls.
- Rechecked the complete managed reward-system baseline. The 1.0.10 reward tables are unchanged from 1.0.9; only an English localization table outside this mod changed.
- Retained all 1.0.9 fixes, persistent named profiles, and the guided return to vanilla.

Existing profiles remain compatible. Underwater rewards automatically use the profile's current Gold and Crafting Materials settings; no profile update is required.

This is a release candidate. Automated table, build, PAK, and UI validation has passed. Please include your `BUILD-REPORT.json`, settings, game build, and conflicting-mod scan when reporting gameplay results.
