# Uninstallation

Close DragonSword: Awakening, then delete this one file from the game folder:

```text
DS\Content\Paks\DS_ZZZ_ProgressionQoL_Configured_P.pak
```

Optional disabled backups are stored here and cannot load while their names end in `.pak.disabled`:

```text
DS\Content\Paks\ProgressionQoL-Backups
```

Delete that backup folder only if you no longer want prior Progression QOL configurations. No registry entries, services, injected DLLs, or files outside the selected build folder and these two owned game locations are created.
